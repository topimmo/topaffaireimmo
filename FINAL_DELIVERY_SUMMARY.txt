🔒 SECURITY IMPLEMENTATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ OTP SECURITY
   • 6-digit cryptographically secure random generation
   • Bcrypt hashing with salt rounds (never plain text)
   • 5-minute TTL with automatic expiration
   • One-time use (deleted after successful verification)
   • Constant-time comparison (prevents timing attacks)

✅ RATE LIMITING
   • 3 OTP requests per hour per phone+IP combination
   • 100 general API requests per 15 minutes per IP
   • Configurable via environment variables
   • Can be disabled in development

✅ BRUTE FORCE PROTECTION
   • Track failed verification attempts
   • Lock account after 5 failed attempts
   • 15-minute lockout period
   • Generic error messages (prevents phone enumeration)

✅ PHONE VALIDATION
   • Morocco-specific validation (+212 country code required)
   • E.164 international format normalization
   • libphonenumber-js validation library
   • Invalid format rejection

✅ JWT SECURITY
   • Secure token generation with secret key
   • Configurable expiration (default: 7 days)
   • Token-based session management
   • Authentication middleware for protected routes

✅ DATABASE SECURITY
   • MongoDB with Mongoose ORM
   • TTL indexes for automatic OTP cleanup
   • No sensitive data in logs
   • Connection string via environment variable

✅ SECRETS MANAGEMENT
   • All credentials via environment variables
   • No hardcoded API keys
   • No hardcoded passwords
   • .env.example template provided
   • .env in .gitignore

📡 API ENDPOINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. POST /auth/otp/request
   Request OTP code via SMS
   
   Request:  {"phone": "+2126XXXXXXXX"}
   Response: {"success": true, "message": "OTP sent successfully"}
   
   Features:
   - Validates Morocco phone number
   - Generates 6-digit OTP
   - Hashes with bcrypt
   - Stores with 5-min TTL
   - Sends via Vonage SMS
   - Rate limited: 3/hour per phone+IP

2. POST /auth/otp/verify
   Verify OTP and get JWT token
   
   Request:  {"phone": "+2126XXXXXXXX", "code": "123456"}
   Response: {
     "success": true,
     "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
     "user": {
       "id": "507f1f77bcf86cd799439011",
       "phone": "+2126XXXXXXXX",
       "createdAt": "2024-01-15T10:30:00.000Z"
     }
   }
   
   Features:
   - Constant-time OTP comparison
   - Creates user if doesn't exist
   - Deletes OTP after verification
   - Returns JWT token
   - Tracks failed attempts

3. GET /health
   Health check endpoint
   
   Response: {
     "success": true,
     "message": "Server is running",
     "timestamp": "2024-01-15T10:30:00.000Z"
   }
