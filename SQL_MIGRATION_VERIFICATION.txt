RLS POLICY VERIFICATION
================================================================================

Artisan UPDATE Policy (091_fix_artisan_location_model.sql, lines 77-99):

✓ Prevents self-verification
✓ Uses WITH CHECK to compare NEW vs OLD values
✓ Allows admin to change all fields
✓ Prevents non-admin from changing is_verified or is_active

Policy Logic:
  - USING: User must own the profile (auth.uid() = user_id)
  - WITH CHECK: 
    - User is admin: Allow all changes
    - User is NOT admin: NEW.is_verified = OLD.is_verified AND NEW.is_active = OLD.is_active

This ensures artisans cannot self-verify or toggle their active status.
